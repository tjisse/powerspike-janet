# PowerSpike 0.23.0

The fight workspace has fewer distractions and more stable controls. The empty
workspace notification, standalone Compare items panel, redundant result text
and extra simulation-details button are removed. Simulation details remain at
the bottom of the results. Event details appear in hover, keyboard-focus and
tap tooltips, with more space around champion names. Patch refresh progress and
cancellation fit within a fixed-size header dropdown.

On **16.20.1 and 16.21.1**, Ahri and Viktor now use the reviewed multi-hit,
recast, empowered-attack and storm behavior, including Viktor's changed shield
value on 16.21.1. Ordinary projectile travel is reviewed for Ahri, Annie and
Viktor on both patches, along with Ahri's attack windup. Viktor's empowered Q
retains its separate, explicitly documented delivery assumption.

The baseline attack-speed cap is now **3.0 on 16.19.1, 16.20.1 and 16.21.1**.
Both combatants, temporary buffs and item optimization share that limit.
Exceptional declared caps remain separate. The latest-patch extension continues
Riot's published baseline after reviewing the matching patch notes; it does not
claim a newly measured server constant.

Existing snapshots remain pinned. Reviewed model corrections apply when loading
supported snapshots without rewriting their saved data. Upgrading does not
reparse snapshots whose older parser rejected ability formulas: use the existing
**Reparse saved data** action, or **Refresh patch data** when retained raw sources
are unavailable. No automatic migration is added.

Upgrade with:

```sh
sudo dnf upgrade --refresh powerspike
```

Administrator configuration and retained patch data are preserved. Results
remain simulations with the displayed omissions; these changes do not add new
in-game measurements or complete champion kits. Existing comparison calculations
and saved imports remain compatible while the standalone comparison workflow
is deferred for redesign.
