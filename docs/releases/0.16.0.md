# PowerSpike 0.16.0

Lich Bane now supplies its temporary attack-speed bonus in simulations and item
optimization. The shared engine uses the champion's attack-speed ratio and cap,
refreshes the priming window without stacking, and removes the bonus on
consumption or expiry. Spellblade cannot prime during its hit cooldown. Both
participants in a duel use independent buff and cooldown state.

The replay checker now accumulates damage totals with the native client's
binary32 arithmetic. This resolves the Ornn total discrepancy without changing
packet amounts or loosening the comparison tolerance. Exact-image native calls
reproduce all 1,012 additions. Clean extraction passes all 100 aggregate checks
across the original replay and an unused replay selected before inspection.

Developer evidence includes the matching-build Ekko replay study, decoded raw
attack-speed components, source excerpts and the discrepancy's native proof.
Private replay files, account identifiers and credentials are excluded from the
release. These checks do not establish per-hit simulation agreement or exact
attack timing. Existing admitted observations retain their model identities.

See [Lich Bane's modeled behavior and timing limits](../lich-bane.md) and
[the replay discrepancy resolution](../replay-damage-accumulation.md).

Local formatting, core and Python suites, frontend and combat regressions,
relocated runtime, RPM payload verification and packaged Chromium checks passed.
Browser checks cover practice item comparisons and paired champion matchups,
including opponent optimization, apply/undo, mobile layouts and native forms.
