# PowerSpike 0.24.0

Champion timelines now show colored duration bands behind the ability icons.
Controls, shields, parry, buffs and ready empowered attacks span their applied
active windows. Overlapping effect types use separate strips inside the existing
lane height. A color key and hover, keyboard-focus and tap tooltips identify each
effect and its timing. Bands account for refreshes, cleanse, consumption,
depleted shields, expiry and death, and stop at the displayed fight end.

Initial pages and configuration updates build their native item-option lists
once per render. This preserves the existing controls and full no-JavaScript
inventories while removing repeated HTML-generation work. Local copied-binary
checks reduced median warm first-byte time from **0.479 to 0.179 seconds** for
practice and **0.763 to 0.202 seconds** for duels. These are local measurements;
hosted performance still needs checking after deployment. The initial HTML
payload remains approximately the same size.

No-JavaScript practice forms now correctly preserve checked and unchecked combat
and objective settings. Native item edits retain physical empty slots and both
champions' independent inventories. JavaScript-enabled forms no longer carry
the native submission marker into ordinary navigation. Concurrent-page checks
now exercise four different matchups while health checks remain responsive.

Upgrade with:

```sh
sudo dnf upgrade --refresh powerspike
```

Administrator configuration and retained patch data are preserved. Results remain
simulations with their existing omissions. Status bands describe modeled effects;
this release adds no new in-game measurements or automatic patch-data migrations.

resource behavior remain separate deployment checks.
