# PowerSpike 0.12.0

Both participants can configure three stat-shard slots under Rune pages. Supported choices include adaptive force, attack speed, ability haste, movement speed, flat health and scaling health. Adaptive force follows the build's stats and the champion's source preference, with explicit AD/AP overrides available.

Scorch, Coup de Grace, Cut Down, Last Stand and Transcendence's level-gated haste join the existing Electrocute handler. Conditional damage bonuses use health immediately before each hit; Scorch uses the selected patch's damage, delay and cooldown. Champion-only bonuses exclude objectives and do not amplify true damage.

Shard bonuses and supported rune effects share the same calculations across build stats, tooltips, combat, optimization and saved/shared/exported scenarios. Shards stay fixed during search. Older scenarios without shard fields remain unsharded, while changed models display their existing compatibility warning.

New downloads retain shard records in their immutable packages. Existing caches can recover them from hash-checked sources. Matching retained excerpts also support 16.18.1 and the initial 16.19.1 package offline. Source hashes remain visible in the evidence view, and the standalone executable embeds the required records and initial adaptive preferences.

New common rune semantics cover the 16.17–16.19 source families. Other rune effects, tenacity/slow-resist shards and Transcendence takedown refunds remain explicit exclusions. These changes add modeled coverage, not new in-game combat calibration.

Verification covers retained formulas, changing health thresholds, delayed hits, level gates, adaptive stats, shard legality, both participants, tooltip recalculation, scenario round trips, fitness-cache separation and optimizer parity. Local core/web suites, browser interactions and the relocated executable checks pass, including packaged rune/shard simulation outside the source tree.

The release uses the existing signed x86_64 RPM and DNF repository workflow. Upgrades preserve cached patches and administrator port settings.
