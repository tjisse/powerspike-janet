# PowerSpike 0.25.0

This release expands the reviewed champion ability models on **16.21.1** and
makes crowded combat events easier to inspect. The developer audit now records
**571 of 692 Q/W/E/R slots applying an effect**, with 94 lacking executable
effects, 18 not casting in the controlled probe and 9 casting without applying
an effect. These are execution counts, not complete-kit or accuracy scores.

The reviewed mechanics include Garen's spins and execute, Seraphine's conditional
healing and control upgrades, Fiddlesticks' interruptible drain and ultimate,
passive attack effects, consumed attack empowerments, defensive protections,
health thresholds, maintained areas, expiring marks and channeled spells.
Every added batch retains its matching source records, independent arithmetic
checks and scenarios for both matchup positions. Important remaining omissions
are documented per spell; some additions deliberately cover only part of an
ability. No new in-game combat captures are claimed.

Crowded timeline markers expose every grouped event, including abilities that
previously appeared to be missing. Hover, focus or tap reveals the group;
individual selection keeps its exact time and artwork. Status bands include the
newly modeled protections, marks, areas and channels without changing lane
heights.

Ordinary fights can remain responsive while item optimization runs. Regression
checks cover independent inventories, queued/running cancellation and an
unaffected neighboring fight. This improves request handling within the current
server; it does not add multiple simulation workers.

Reviewed item, rune and fixed-form behavior also extends to the retained latest
patches. Existing patch data is preserved: use the existing explicit reparse or
refresh controls when needed. This release keeps parser version **7** and adds
no automatic migration or patch-data repair process.

Upgrade with:

```sh
sudo dnf upgrade --refresh powerspike
```

Administrator configuration and retained raw/parsed patch packages are
preserved. Results remain simulations with their declared assumptions and
incomplete champion kits.

Core/source, combat/frontend, relocated runtime, concurrency and full browser
checks passed before release preparation. The latest batch adds 50 retained
standalone and desktop/mobile scenarios. Publication additionally verifies the
RPM payload, signs the package and repository metadata, and tests installation
through the signed DNF repository.
