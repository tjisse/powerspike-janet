# PowerSpike 0.10.1

The gold budget is now configured only in the Optimize build dialog. The main loadout tray shows the selected inventory and its total cost, with Optimize build directly below the item slots. The budget input and remaining-gold display have been removed from that tray.

Optimization still uses the configured gold limit, and recommendations retain the budget used for each search. Next-purchase mode continues to treat the budget as gold available now.

Frontend and browser verification cover the simplified tray and the existing optimization, apply, cancel, save/share and responsive-layout interactions. The release uses the existing signed x86_64 RPM and DNF repository workflow.
