# PowerSpike 0.26.0

This release expands the reviewed champion ability models on **16.21.1** with
100 additional ability slots covering sustain, charged abilities and other
remaining mechanics. Duel prerequisites are classified to make matchup
assumptions clearer. As before, modeled effects have documented limitations
and do not imply that every champion kit is complete.

The shared fight graph and HP overview now show champion distance over time,
making movement and range changes easier to compare with damage and health.

Upgrade with:

```sh
sudo dnf upgrade --refresh powerspike
```

Administrator configuration and retained raw/parsed patch packages are
preserved. Results remain simulations with their declared assumptions and
incomplete champion kits.
