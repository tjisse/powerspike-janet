# PowerSpike 0.10.0

Champion level now determines unlocked abilities and learned ranks from an explicit skill order. Both player and opponent have a populated, editable Q/W/E/R sequence under Strategies, ranks & activation rules. Casting priority stays independent, and manual rank settings still override the learned ranks.

Ability icons use fixed-size tiles with the letter in the bottom-left corner. Circles below each icon show the available ranks, with learned ranks filled in gold. Unlearned abilities appear dimmed and remain inspectable. Locking or unlocking an ability no longer changes its width or shifts neighboring icons.

Saved, shared and imported scenarios preserve skill orders and manual rank overrides. Loading a scenario keeps automatic ranks automatic, so later level changes apply the saved order correctly. Optimization skill locks display and retain the configured choices at each level.

Scenario documents must include a skill order for each champion, with enough entries to cover the selected level. Older documents without skill orders are rejected with an explanation. Exceptional champion leveling rules remain outside the current standard rank validation.

Frontend regressions cover every champion level, independent cast priorities, both participants, missing or invalid orders, manual overrides and saved-scenario level changes. Browser verification checked rank circles and unchanged icon positions at levels 1, 3, 6 and 18, including narrow layouts.

The release uses the existing signed x86_64 RPM and DNF repository workflow. Combat estimates and their existing coverage limitations remain separate from in-game validation.
