# PowerSpike 0.20.0

Save configured champions, swap opponents and inspect why a build changes a
simulated fight. This release also corrects combat timing and strengthens
concurrent requests, provider downloads and cache storage.

- Four named browser save slots preserve a champion's form, level, item slots,
  runes, summoners, ranks and strategy. Load a configuration on either side.
  Swap exchanges both complete configurations while preserving shared fight
  settings. The completed result stays visible until you run the matchup again.
- Build comparisons show survival tradeoffs, damage changes by ability, attack,
  item and rune source, and observed variation across matching simulation
  trials. Saved and shared comparisons preserve both inventories.
- Combat timeline ability, item and rune icons and champion portraits return,
  with keyboard selection, mobile support and readable artwork fallbacks.
- Attacks and supported abilities wake at their exact readiness deadlines,
  including cooldowns, control expiry, attack resets, resource recovery, health
  thresholds and movement into range. Supported changing costs and ranges are
  recalculated when stats or buffs change.
- Character-level stat interpolation now respects the retained progression
  flags. Reviewed projectile timing covers Human Nidalee and Elise attacks and
  Jayce's ordinary Cannon attacks.
- Concurrent simulations and long result rendering keep HTTP requests
  responsive. Cancellation releases queued work, idle downloads can be
  cancelled, managed writes enforce the configured data allowance, and failed
  artwork requests share a bounded retry window.

Results remain simulations of the selected patch, configurations and strategies.
Trial ranges describe observed simulated outcomes, not win probabilities.
Unsupported mechanics and remaining timing assumptions stay visible in
Simulation details. These source-backed corrections and regression checks do
not add newly admitted in-game combat measurements.

Champion slots are local to the browser and require the same patch snapshot.
Existing scenario and comparison exports remain supported. Cached patches remain
readable when the storage allowance is reached; automatic cache eviction is not
included. Run one writing service process per data directory.
