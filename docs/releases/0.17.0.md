# PowerSpike 0.17.0

Champion attack ranges now survive catalog import for all 173 champions.
Existing 16.19.1 snapshots recover missing baseline ranges from the matching,
hash-checked source without changing snapshot bytes or identifiers. This fixes
the unintended 125-unit fallback, which could make ranged champions approach
melee distance or fail to attack while holding position. New catalog data also
triggers a seed rebuild.

Ahri's ordinary and critical attacks now use the retained projectile speed of
1,750 units/second. Damage arrives after travel rather than immediately at
release. Both duel participants, item comparisons and optimization use the same
behavior. The standalone executable embeds the required source data.

Regression cases cover every baseline range, old snapshot repair, exact patch
isolation, all three Ahri attack variants, in-range and out-of-range attacks,
impact at the scoring boundary and direct/optimizer agreement. The relocated
runtime checks Ahri's first impact and Annie's additional attack at her proper
range. See [attack range and projectile timing](../attack-projectiles.md).

Windup remains the configured 30% assumption. Other projectile profiles and
exceptional weapon/form rules await their own handlers and evidence. These
source-derived changes do not admit new in-game timing measurements. Saved
scenarios retain their data identities and warn before recomputing with a
different combat model.

Local formatting, core/source/Python suites, frontend and combat regressions,
relocated runtime, RPM payload verification and packaged Chromium checks passed.
Browser checks cover practice comparisons, paired champion matchups, opponent
optimization, apply/undo, mobile layouts and native forms.

The [clean packaging and browser workflow](https://github.com/tjisse/powerspike-janet/actions/runs/39293902015)
and [signed publication and DNF installation workflow](https://github.com/tjisse/powerspike-janet/actions/runs/39293901860)
passed. The downloaded RPM matches its published checksum and verifies against
the dedicated PowerSpike key. Installation checks cover upgrade, preservation
of edited configuration and cached snapshots, reinstall and removal.
