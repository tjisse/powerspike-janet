# PowerSpike 0.22.0

The matchup workspace is cleaner and more stable. Champion customization tabs
keep a consistent size, the swap control is an icon between the champions, and
item artwork is compact. Patch selection and download progress live in the
header. The combat graph and event lanes now share one timeline with pointer,
touch and keyboard inspection, without a separate time slider.

The item optimizer has a fixed-size dialog, visible scrollbars, separate
settings and recommendation panes, contained item sets and consistent apply
buttons. Starting a search preserves the dialog position and completed results;
apply actions remain disabled while the search runs.

Workspace warnings and action prompts now share a prominent **Needs attention**
area above the champions. Stale results, parser mismatches, configuration and
patch failures, model differences and save recovery include their relevant
actions. The area keeps a stable size as messages appear and resolve.

Newly refreshed **16.20.1 and 16.21.1** data correctly interprets the reviewed AP,
AD and health formulas and restores Annie/Garen ability execution in the default
matchup. Saved data with an older parser offers **Reparse saved data** when its
raw sources are retained. This manual action verifies the source hashes and
uses the current parser without provider downloads. Old snapshots and saved
links remain pinned. When raw sources are unavailable, use **Refresh patch
data** to download them. Upgrading alone does not reparse saved snapshots.

The reviewed baseline attack-speed cap is corrected to **3.0 on 16.19.1**,
including temporary buffs, both combatants and item optimization. Matchups also
accept supported fractional fight durations when rerun. Other patches and
exceptional cap rules retain their existing scope.

Upgrade with:

```sh
sudo dnf upgrade --refresh powerspike
```

Administrator configuration and retained patch data are preserved. Results
remain simulations with their existing omissions. These changes do not add new
in-game combat measurements or claim complete champion kits.
