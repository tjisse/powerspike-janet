# PowerSpike 0.18.0

Melee/ranged item scaling now uses the champion's retained identity instead of
guessing from attack range. This corrects Lillia's Blade of the Ruined King
on-hit rate without changing her 325-unit range. Item tooltips, both duel
participants and optimizer fitness use the same classification.

The catalog preserves 89 melee identities, 79 ranged identities and five
form-dependent identities. Existing 16.19.1 snapshots recover missing identities
from hash-checked matching sources without rewriting their bytes. Newly fetched
snapshots derive the identity from their own CharacterRecords. The executable
embeds the retained identities for offline upgrades.

Elise, Gnar, Jayce, Kayle and Nidalee need form or level transitions that are not
yet modeled. Their conditional Mist's Edge on-hit damage is explicitly excluded
until their attack type can be resolved. Ordinary supported item stats still
apply. Simulation details explain the omission, and tooltips avoid a fabricated
percentage or an internal template token.

Source/classification regressions cover all 173 champions, Lillia's independently
calculated proc damage, fresh and cached data, tooltips, both participants,
optimizer agreement and the five unresolved champions. The standalone runtime
also exercises an upgrade using the signed v0.17.0 RPM's older seed in an empty
directory. See [melee/ranged item scaling](../attack-styles.md).

This corrects classification and reports remaining scope. It does not implement
champion transformations or add newly admitted in-game combat measurements.

Local formatting, core/source/Python checks, frontend and combat regressions,
standalone runtime, RPM payload verification and packaged Chromium checks passed.
Browser checks include practice comparisons, paired matchups, optimizer
apply/undo, mobile layouts and native forms.
