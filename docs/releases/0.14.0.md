# PowerSpike 0.14.0

The main screen now configures a champion and an opponent together. Each has an
independent level, inventory, runes, shards, summoner spells and attack sequence.
Panels appear side by side on desktop and collapse into editable summaries on
mobile. Detailed settings are closed by default, and champion defenses come from
their builds.

Run a matchup to compare both champions on one health or damage graph. The result
shows the first knockout and remaining health, with a shared time cursor and
selectable combat events. Configuration edits update build stats and mark the
previous fight as outdated until the next run.

Optimize items beside either inventory while holding the opponent, runes and
strategy fixed. Keep selected items, compare the current build with a proposed
build, then apply or undo the inventory changes. Existing practice, objective and
reference scenarios retain their controls.

This release changes configuration and presentation; the modeled combat engine
remains the source of simulation results. Existing coverage limits still apply.
