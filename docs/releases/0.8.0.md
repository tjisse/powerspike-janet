# PowerSpike 0.8.0

The Rift HUD puts champion, level, stats, items and gold together, with secondary controls in expandable groups. Champion, ability, item and rune details use shared popovers. Hovering or selecting an attack highlights the corresponding event across damage, health and resource graphs.

Optimization opens a modal without starting a search. Run search starts the job; closing and reopening the modal retains its progress. Results are up to ten rows ranked by the selected scoring preset, with metrics, shared item popovers, expandable loadout/coverage details and Apply & inspect. Comparison graphs have been removed from this modal.

The search seeds complete legal builds and explores mutations and crossovers. Shop availability, purchase unlocks and separate trinket slots are checked. Completed combat evaluations are reused in a bounded, immutable fitness cache across workers. Cancellation uses independent in-memory signals; metrics-only evaluation, precomputed ordering hashes and throttled progress reduce overhead. Patch download descriptions no longer change control widths.

Existing scenarios, saved/share/JSON reproduction, declared combat strategies and calibration remain available. Cache keys include exact data/model/scenario/trial identities, and partially cancelled trials are never cached. The fitness cache resets on restart.

Champion and item effects still have explicit coverage gaps. Rankings are estimates within the modeled scenario; heuristic results are labeled Best found.

The release supplies a signed x86_64 RPM through the existing DNF repository. Upgrades preserve cached patches and administrator port settings.
