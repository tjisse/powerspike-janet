# PowerSpike 0.11.0

Supported tooltip placeholders now display colored calculated values for the selected build and ability rank. Hover or focus a value to inspect its formula, including rank, level and stat contributions; click to keep the explanation open. Unknown formulas and unavailable inputs retain their original placeholders.

Ability, item, rune and summoner tooltips use the shared Janet expression evaluator. Values reflect starting fight conditions, and damage is shown before mitigation. Equipped items and optimization recommendations use their own build stats. Item-picker details are calculated on demand for the current participant and the scenario's exact patch snapshot, with bounded caching and cancellation when another tooltip opens.

The initial curated Annie Q/W subset also exposes its modeled damage calculation. Resolving a tooltip value does not establish that the corresponding combat trigger is implemented or validated; existing coverage notes remain available.

Verification covers retained damage and percentage formulas, rank and inventory changes, unknown placeholders, exact-snapshot requests, invalid inputs, hover/focus/pinning, and the existing optimization, save/share and responsive-layout interactions. The release uses the signed x86_64 RPM and DNF repository workflow.
